# Map Explorer 한국어 포크 (클래식 + 리테일)

내 컴퓨터에 설치된 **월드 오브 워크래프트(WoW)** 게임 파일을 직접 읽어서, 아제로스를 하늘에서 날아다니며 구경할 수 있는 웹 앱입니다.
게임에 로그인하지 않아도 되고, 인터넷도 필요 없습니다. 지도·지형·건물·물·하늘이 모두 **내 PC의 게임 데이터**에서 그려집니다.

이 저장소는 [Coldensjo/ClassicWowMapExplorer](https://github.com/Coldensjo/ClassicWowMapExplorer)(v0.3.1)를 **포크**해서 고친 버전입니다.
원작은 WoW 클래식용이고, 이 포크는 여기에 아래 기능을 더했습니다.

- **리테일(본섭) 에디션**: 지금 게임의 지형으로 칼림도어·동부 왕국·줄다자르·혼돈의 소용돌이·심원의 영지를 둘러볼 수 있습니다.
- **행성 아제로스 보기**: 아주 높이 올라가면 아제로스가 우주에서 본 둥근 행성으로 바뀝니다. 프로그램을 처음 열면 이 행성 보기에서 시작합니다.
- **볼거리**: 실리더스의 **살게라스의 검**, 하늘에 떠 있는 **아르거스**, 스톰윈드 정문 위의 **데스윙**(모두 리테일)
- **창 하나에서 클래식 ⇄ 리테일 전환** (보던 장소·시점·시간대 유지)
- 낮과 밤이 제대로 바뀌고, 한낮 색감이 자연스럽게
- 물속도 물 밖처럼 밝고 멀리 보임 (바닷속 지역 **바쉬르**도 둘러볼 수 있음)
- 새 단축키(E·D·W·R 비행), 드래그로 시점 이동, WoW 건틀릿 마우스 포인터
- **Shift+B**로 칼림도어·동부 왕국 **대륙 전체 지도** 팝업 (리테일, 지도 그림은 직접 넣는 파일)
- 클릭하면 전체 화면, **Alt+Z**로 UI 숨기기(행성 보기에서는 자동으로 숨김), 창이 뒤로 가면 소리 자동 음소거

> 원작자의 영어 설명서는 [README.en.md](README.en.md)에 그대로 남겨 두었습니다.

## 무엇을 할 수 있나요?

- 동부 왕국과 칼림도어를 **하나로 이어진 세계**로 자유롭게 날아다니기
- 지형, 물과 용암, 건물과 소품, 풀·꽃 같은 바닥 장식, 불·연기 효과
- 게임 그대로의 **하늘, 안개, 시간대별 빛** (시간 조절 가능), 비·눈·모래폭풍 같은 날씨
- 지역 이름과 **지역 음악**, 지역별 환경음 (새소리, 바람, 도시 소음 등)
- 게임 속 **세계 지도**와 **미니맵**, 지역·마을 **검색**으로 순간 이동
- **걷기 모드**: 캐릭터를 땅에 내려 게임처럼 뛰고, 점프하고, 수영하기
- (클래식) **NPC·몬스터**, 비행 경로, 배·비행선 운항, 던전 입구와 만남의 돌
- (리테일) 지금 게임의 지형과 랜드마크, 행성 아제로스와 그 위의 볼거리

## 필요한 것

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10 또는 11 (리눅스·맥은 [소스에서 실행](#소스에서-바로-실행하기-개발-서버)) |
| 게임 | Battle.net으로 설치한 **WoW 클래식**(클래식 에라 포함). 리테일 에디션을 쓰려면 **리테일(본섭)**도 설치되어 있어야 합니다. |
| 브라우저 | Microsoft Edge 또는 Chrome (Windows에는 Edge가 기본으로 있습니다) |
| 직접 빌드할 때만 | [Node.js](https://nodejs.org) 22.12 이상 (LTS 권장), git |

게임은 보통 `C:\Program Files (x86)\World of Warcraft` 에 설치되어 있고, 그 안에 `_classic_era_`, `_classic_`, `_retail_` 같은 폴더가 있습니다.
앱은 이 폴더를 **읽기만** 하고, 어떤 파일도 수정하거나 밖으로 보내지 않습니다.

## 설치 방법 (Windows, 추천)

원작의 **포터블 실행 파일**(`MapExplorer.exe`)에 이 포크에서 빌드한 앱을 넣어 쓰는 방법입니다.
실행 파일은 원작자 릴리스를 그대로 쓰고, 화면에 보이는 앱 부분(`app` 폴더)만 이 포크의 것으로 바꿉니다.

### 1단계. 원작 포터블 버전 받기

1. [원작 v0.3.1 릴리스](https://github.com/Coldensjo/ClassicWowMapExplorer/releases/tag/v0.3.1)에서 **MapExplorer-portable.zip**을 받습니다.
2. 원하는 곳에 압축을 풉니다. 예: `C:\Tools\MapExplorer\`
   압축을 풀면 `MapExplorer\MapExplorer.exe`와 `MapExplorer\app\` 폴더가 생깁니다.

### 2단계. 이 포크 빌드하기

명령 프롬프트(또는 PowerShell)를 열고 차례대로 실행합니다.

```bash
git clone -b ko-edition https://github.com/betraymenow/ClassicWowMapExplorer.git
```

```bash
cd ClassicWowMapExplorer
```

```bash
npm install
```

```bash
npm run build
```

빌드가 끝나면 `dist` 폴더가 생깁니다.

- `dist\` : 클래식 에디션
- `dist\retail\` : 리테일 에디션

### 3단계. app 폴더 바꾸기

1. 1단계에서 푼 `MapExplorer\app` 폴더를 지우거나 다른 이름(예: `app.original`)으로 바꿉니다.
2. 2단계의 `dist` 폴더를 `MapExplorer` 폴더 안에 복사하고, 이름을 **`app`** 으로 바꿉니다.

최종 구조는 다음과 같습니다.

```
MapExplorer\
├─ MapExplorer.exe
├─ app\              ← 이 포크의 dist 폴더
│  ├─ index.html     (클래식)
│  ├─ assets\ ...
│  └─ retail\        (리테일)
└─ README.txt
```

### 4단계. 실행

1. `MapExplorer.exe`를 더블클릭합니다.
2. 처음 실행하면 Windows가 **"Windows의 PC 보호"** 경고를 띄울 수 있습니다. 실행 파일에 서명이 없어서 그렇습니다. **추가 정보 → 실행**을 누르면 됩니다.
3. 앱이 WoW 설치 폴더를 스스로 찾아서 바로 세계가 열립니다. 처음에는 **리테일 행성 보기**에서 시작합니다.
   못 찾으면 **Choose your World of Warcraft folder** 버튼을 눌러 `World of Warcraft` 폴더(`_classic_era_` 등이 들어 있는 폴더)를 고르세요.

> 포터블 실행 파일은 `app` 폴더를 내 PC 안에서만 접속되는 주소(`http://127.0.0.1:51730`)로 띄우고, Edge를 탭·주소창 없는 **앱 창**으로 엽니다. 창을 닫으면 함께 종료됩니다.

## 소스에서 바로 실행하기 (개발 서버)

포터블 exe 없이, 개발 서버로 실행할 수도 있습니다. 리눅스(Wine 등)나 맥에서도 이 방법을 씁니다.

```bash
npm install
```

클래식 에디션:

```bash
npm run dev
```

리테일 에디션:

```bash
npm run dev:retail
```

그다음 Chrome 또는 Edge에서 **http://localhost:5173** 을 엽니다.
WoW가 다른 곳에 설치되어 있다면 `WOW_DIR` 환경 변수로 알려 주세요.

```bash
WOW_DIR="D:/Games/World of Warcraft" npm run dev
```

> 개발 서버에서는 클래식과 리테일이 서로 다른 서버로 뜨기 때문에 **전환 버튼은 보이지 않습니다.**

## 사용법

1. 3D 화면을 **클릭**하면 **전체 화면**으로 바뀝니다. **Esc**를 누르면 창으로 돌아옵니다.
2. **왼쪽 버튼을 누른 채 드래그**하면 둘러볼 수 있습니다.
3. **E·D·W·R** 키로 앞·뒤·왼쪽·오른쪽으로 날아다닙니다. **Shift**를 누르고 있으면 빨라집니다.
   마우스 **왼쪽+오른쪽 버튼을 함께 누르고 있으면** 빠르게 앞으로 날아갑니다.
4. 마우스만 움직여 둘러보고 싶으면 **Caps Lock**으로 마우스를 잠그세요. 다시 누르면 풀립니다.
5. 화면 왼쪽 위 메뉴에서 여러 설정을 바꿀 수 있습니다.
   - **View**: 시간, 비행 속도, 그림자·안개, NPC·오브젝트 표시, 날씨 등
   - **Sound**: 음악·효과음·환경음 볼륨
   - **Travel**: 비행 경로 타기, 배·비행선 타기, 걷기 모드
   - **Highlight**: 상자·약초·광석·낚시터 등을 멀리서도 보이게 강조
   - **Retail ⇄ / Classic ⇄**: 에디션 전환 ([아래 설명](#클래식--리테일-전환))
6. 오른쪽 위 검색창(**/** 키)에 지역·마을 이름을 입력하면 그곳으로 이동합니다.
7. **F1** 또는 **?** 키를 누르면 단축키 도움말이 나옵니다.
8. **Alt+Z**(또는 **U**)를 누르면 화면의 모든 UI가 숨겨지고 3D 화면만 남습니다. 행성 보기로 바뀌면 UI가 자동으로 숨겨지고, 평면 지도로 내려오면 다시 나타납니다.

## 단축키 전체 목록

이 포크는 원작과 단축키가 다릅니다. **바뀐 키는 굵게** 표시했습니다.

### 비행 (키보드)

| 키 | 동작 | 원작 키 |
|---|---|---|
| **E** / **D** | 앞으로 / 뒤로 | W / S |
| **W** / **R** | 왼쪽 / 오른쪽 | A / D |
| **S** / **F** | 제자리에서 왼쪽 / 오른쪽으로 돌기 | (없음) |
| Space | 위로 | Space / E |
| C 또는 **X** | 아래로 | C / Q |
| 방향키 | 앞·뒤·좌·우 | 같음 |
| Shift | 모든 방향 빠르게 (5배) | 같음 |
| **Caps Lock** | 마우스 잠그기 켜기/끄기 | (없음) |
| G | 벽·바닥·땅 통과 켜기/끄기 | 같음 |
| J | 시네마틱 카메라 | 같음 |
| Esc | 전체 화면 끝내기 | 마우스 풀기 |

### 비행 (마우스)

| 동작 | 결과 | 원작 |
|---|---|---|
| **왼쪽 클릭** | 아무 일도 없음. 처음 클릭하면 전체 화면으로 바뀜 | 마우스 잡기 |
| **왼쪽 버튼 드래그** | 시점 이동 (드래그하는 동안 포인터가 숨음) | (없음) |
| 오른쪽 클릭 | 아무 일도 없음 | 같음 |
| **왼쪽+오른쪽 동시 누르기** | 누르는 동안 **빠르게 앞으로** | (없음) |
| NPC·오브젝트 클릭 | 정보창 열기 | 같음 |
| 마우스 휠 | 확대 / 축소 | 같음 |
| Caps Lock으로 잠근 상태 | 버튼 없이 마우스만 움직여 시점 이동. 클릭하면 조준점 위치의 NPC 정보를 엶 | 클릭으로 잠그기 |

### 장소 이동

| 키 | 동작 | 원작 키 |
|---|---|---|
| / | 지역·마을·맵 검색해서 이동 | 같음 |

| **3 / 4 / 5** | 줄다자르 / 혼돈의 소용돌이 / 심원의 영지 (리테일만) | (없음) |
| **O** | [행성 아제로스 보기](#행성-아제로스-보기) 켜기/끄기 | 세계 전체를 위에서 보기 |
| **T** | 행성 보기 시작 시점으로 | R |
| **M** | 세계 지도 | Tab |
| **Shift+B** | [대륙 전체 지도](#대륙-전체-지도) (리테일) | (없음) |
| Esc | 비행 경로·배·비행선에서 내리기 | 같음 |

### 걷기 모드

숫자 1 왼쪽의 **`** 키(또는 Travel 메뉴의 *Walk on the ground*)로 캐릭터를 땅에 내리고, 다시 누르면 비행으로 돌아갑니다.

| 키 | 동작 | 원작 키 |
|---|---|---|
| **E** / **D** | 달리기 / 뒷걸음질 | W / S |
| **W** / **R** | 왼쪽 / 오른쪽으로 돌기 (오른쪽 마우스 버튼을 누르고 있으면 옆걸음) | A / D |
| **X** | 왼쪽 옆걸음 | Q / E |
| Space | 점프, 물속에서는 위로 | 같음 |
| **C** | 물속에서 아래로 | X |
| \ 또는 숫자패드 / | 걷기 / 달리기 전환 | 같음 |
| 왼쪽 마우스 드래그 | 캐릭터 주위로 카메라 돌리기 | 같음 |
| 오른쪽 마우스 누르고 있기 | 캐릭터도 함께 돌기 (두 버튼 동시에 누르면 앞으로 달리기) | 같음 |
| 마우스 휠 | 카메라 거리 | 같음 |

## 낮과 밤 바꾸기

처음에는 **내 PC의 현재 시각**에 맞춰 낮과 밤이 정해집니다. 바꾸는 방법은 세 가지입니다.

| 방법 | 설명 |
|---|---|
| **View 메뉴 → Time 막대** | 막대를 끌면 원하는 시각으로 바로 바뀝니다. **Now** 버튼은 현재 시각으로 되돌립니다. |
| **Y 키 누르고 있기** | 누르는 동안 시간이 빠르게 흐릅니다. **Shift+Y**는 거꾸로 흐릅니다. |
| **N 키** | 현재 시각으로 되돌립니다. |

밤이 너무 어두우면 **L** 키로 횃불 조명을 켜 보세요.

덕분에 깊은 바닷속 지역인 [바쉬르](#바쉬르)도 밝게 둘러볼 수 있습니다.

## 행성 아제로스 보기

아주 높이 올라가면 아제로스가 우주에서 본 **둥근 행성**으로 바뀝니다. (클래식·리테일 모두)
행성 보기로 바뀌면 화면의 UI가 자동으로 숨겨지고, 평면 지도로 내려오면 다시 나타납니다. 어느 쪽에서든 **Alt+Z**(또는 **U**)로 켜고 끌 수 있습니다.

**들어가는 방법**

- **처음 실행:** 리테일 행성 보기에서 행성 음악과 함께 시작합니다.
- **O** 키: 지금 보고 있는 곳을 정면에 두고 행성 보기로 바뀝니다.
- **T** 키: 행성 보기 시작 시점으로 갑니다(리테일은 혼돈의 소용돌이 위, 클래식은 두 대륙 사이 바다 위).
- 비행하다가 아주 높이(약 40,000야드) 올라가면 저절로 바뀝니다.

**조작**

| 조작 | 동작 |
|---|---|
| 왼쪽 버튼 드래그 | 행성 돌리기 |
| 마우스 휠 | 확대·축소 |
| 더블클릭 | 그 지점으로 내려가기 |
| 끝까지 확대, 또는 O | 화면 가운데 지점으로 내려가기 |
| 1~5 | 해당 대륙으로 바로 이동 |
| T | 행성 보기 시작 시점으로 |
| Y / Shift+Y | 시간 흐름 (낮·밤 경계, 구름, 자전이 빨라짐) |

**행성에서 볼 수 있는 것**

- 숲, 초원, 사막, 바위산, 늪, 설원 같은 **자연색 대륙**과 산맥 음영
- 짙은 바다와 해안의 얕은 바다, 극지방의 해빙
- 동쪽으로 흘러가는 **반투명 구름**과 그 그림자
- 리테일에서는 칼림도어와 동부 왕국 사이에 **혼돈의 소용돌이** 회오리 구름
- 천천히 **자전**하는 행성, 우주에 고정된 태양, 대륙 위를 지나가는 낮·밤 경계
- 별과 성운이 있는 우주 배경, 행성 가장자리의 푸른 대기 빛
- 리테일에서는 실리더스의 **살게라스의 검**과 우주에 떠 있는 **아르거스**

행성에서 내려오면 원래 아제로스 맵으로 이어지고, 보던 곳이 화면 가운데에 옵니다.

**행성 보기 음악** (리테일 전용)

행성 보기 동안에는 지역 음악 대신 **행성 전용 음악**이 반복 재생됩니다. 음악 파일은 게임 음악이라 저장소에 들어 있지 않습니다. 원하는 MP3를 **`public/music/planet.mp3`**에 두고 빌드하세요(이미 빌드한 앱이라면 `app/music/planet.mp3`와 `app/retail/music/planet.mp3`). 파일이 없으면 행성 보기는 조용합니다.

## 대륙 전체 지도

리테일에서 **Shift+B**를 누르면 지금 있는 대륙(칼림도어 또는 동부 왕국)의 **전체 지도**가 화면 가운데 큰 창으로 뜹니다. 행성 보기에서는 화면 정면에 보이는 대륙의 지도가 뜹니다.

| 조작 | 동작 |
|---|---|
| 마우스 휠 | 커서 위치를 기준으로 확대·축소 (화면 맞춤의 최대 10배) |
| 드래그 | 지도 이동 |
| Shift+B, Esc, 지도 바깥 클릭 | 닫기 |

- 지도가 떠 있는 동안에는 비행 키가 움직이지 않습니다.
- 줄다자르, 혼돈의 소용돌이, 심원의 영지에는 이 지도가 없습니다.
- 지도 그림은 저장소에 **들어 있지 않습니다**(게임 지도 그림이라 공개하지 않음). 직접 준비한 그림을 **`public/maps/kalimdore.jpg`**(칼림도어)와 **`public/maps/east_kingdom.jpg`**(동부 왕국)에 두고 빌드하세요(이미 빌드한 앱이라면 `app/retail/maps/`). 파일이 없으면 Shift+B를 눌렀을 때 안내만 나옵니다.

## 클래식 ⇄ 리테일 전환

[포터블 방식](#설치-방법-windows-추천)으로 설치했다면, 화면 왼쪽 위 메뉴 오른쪽에 전환 버튼이 있습니다.

- 클래식 화면: **Retail ⇄** 를 누르면 리테일로 바뀝니다.
- 리테일 화면: **Classic ⇄** 를 누르면 클래식으로 돌아갑니다.

전환해도 **보던 장소와 시점, 행성 보기 상태, 시간대, 설정**이 그대로 이어집니다.

알아 두면 좋은 점:

- 전환하면 게임 데이터를 다시 불러오므로 **몇 초 로딩**이 있습니다.
- 상대 버전에 없는 장소(리테일의 줄다자르·소용돌이·심원의 영지, 클래식의 던전 등)에서 전환하면 시작 위치에서 열립니다.
- 리테일 버튼은 `app\retail\` 폴더가 있을 때만 나타납니다.

## 리테일에서 볼 수 있는 것

리테일 에디션은 지금 게임(본섭)의 지형으로 아제로스를 보여 줍니다.

### 지역

| 지역 | 설명 | 이동 |
|---|---|---|
| **동부 왕국** | 대격변 이후 모습 | 1 |
| **칼림도어** | 대격변 이후 모습. 실리더스는 살게라스의 검이 꽂힌 지금 모습 | 2 |
| **줄다자르** | 격전의 아제로스 대륙. 두 대륙 남쪽 바다에 놓임 | 3 |
| **혼돈의 소용돌이** | 칼림도어와 동부 왕국 사이 바다의 거대한 소용돌이 | 4 |
| **심원의 영지** | 소용돌이 아래 땅속 세계 | 5 |
| **바쉬르** | 동부 왕국 서쪽 바다 깊은 곳 | 검색 |

던전, 레이드, 다른 대륙(노스렌드, 판다리아, 쿨 티라스 등)은 넣지 않았습니다.

### 혼돈의 소용돌이와 심원의 영지

**4** 키로 소용돌이에 간 뒤, 소용돌이 한가운데 **눈** 위에서 **C** 또는 **X**로 계속 내려가면 화면이 잠깐 어두워졌다가 **심원의 영지** 하늘로 이어집니다. 심원의 영지에서 대지의 사원 위로 높이 올라가면 다시 소용돌이로 돌아옵니다. **5** 키로 심원의 영지에 바로 갈 수도 있습니다.
땅속이라 어두운 심원의 영지는 지형이 잘 보이도록 밝게 보여 줍니다.

### 바쉬르

바쉬르(켈프타르 숲, 일렁이는 해원, 심연의 나락)는 해수면 아래 깊은 곳에 있습니다.

1. `/` 검색에서 **Kelp'thar Forest**, **Shimmering Expanse**, **Abyssal Depths** 등을 찾아 이동합니다.
2. 바다 위에 도착하면 **C** 또는 **X**로 내려갑니다(Shift를 같이 누르면 빠름).
3. 해저에 가까워지면 산호, 해초, 암반 지형이 보입니다.

### 실리더스와 살게라스의 검

실리더스에는 지금 게임처럼 거대한 **살게라스의 검**이 꽂혀 있습니다. 상처 구덩이와 빛나는 아제라이트 균열, 검을 감싼 **붉은 기운과 연기**까지 보입니다. 검이 워낙 커서 칼림도어 어디서든, 아주 높이 올라가도 보이고, 행성 보기에서도 랜드마크처럼 솟아 있습니다.
처음 실리더스 근처로 가면 검이 나타나기까지 잠시 걸릴 수 있습니다.

### 하늘의 아르거스

레기온 7.3 때처럼, 지옥불에 휩싸인 **아르거스** 행성이 아제로스 동남동쪽 하늘에 떠 있습니다. 녹색 지옥불 균열과 불꽃, 떠다니는 파편이 보이고 밤에도 빛납니다. 행성 보기에서는 아제로스 뒤 우주에 떠 있습니다.

### 스톰윈드 정문의 데스윙

대격변 확장팩 로그인 화면처럼, 스톰윈드 정문 위에 **데스윙**이 두 탑을 발톱으로 움켜쥐고 앉아 있습니다. 정문 앞 다리에서 올려다보면 로그인 화면과 같은 구도가 됩니다. 정문을 압도할 만큼 크고, 숨을 쉬며 고개와 날개를 움직입니다. 멀리서도 보입니다.

위 볼거리(살게라스의 검, 아르거스, 데스윙, 소용돌이 회오리, 행성 음악)는 리테일에만 있고, 클래식은 원래 모습 그대로입니다.

## 자주 묻는 질문 / 문제 해결

**Q. "Windows의 PC 보호" 창이 떠요.**
A. 실행 파일에 디지털 서명이 없어서 나오는 경고입니다. **추가 정보 → 실행**을 누르세요.

**Q. 게임 폴더를 못 찾는다고 나와요.**
A. **Choose your World of Warcraft folder**를 눌러, `_classic_era_`·`_retail_` 등이 들어 있는 **World of Warcraft 폴더 자체**를 고르세요. 창에 "업로드"라고 나와도 파일은 내 PC 밖으로 나가지 않습니다.

**Q. 클래식 버전인데 오리지널 클래식 지도가 아니고, 소리도 안 나요.**
A. 판다리아 클래식 같은 **클래식 진행 서버**를 함께 설치했다면 생길 수 있었던 문제입니다. 이 포크는 **클래식 에라**를 가장 먼저 고르도록 고쳤습니다.

**Q. 시간이 지나도 낮과 밤이 안 바뀌어요.**
A. 원작에서는 클래식 에라·리테일의 조명을 읽지 못했는데, 이 포크에서 고쳤습니다. 여전히 그렇다면 **F5**로 새로고침해 보세요.

**Q. 다른 창을 보고 있으면 소리가 안 나요.**
A. Map Explorer 창이 **뒤로 가거나 최소화되면 자동으로 음소거**합니다. 창으로 돌아오면 다시 소리가 납니다.

**Q. 전체 화면은 어떻게 하나요?**
A. 3D 화면을 클릭하면 자동으로 전체 화면이 됩니다. **Esc**를 누르면 창으로 돌아옵니다. **F11**로도 켜고 끌 수 있습니다. 에디션 전환이나 새로고침을 하면 전체 화면이 풀립니다.

**Q. 화면 위에 "Esc를 누르면 …" 같은 안내 문구가 떠요.**
A. 브라우저가 전체 화면에 들어가거나 마우스를 잠글 때 띄우는 보안 안내라서 끌 수 없습니다.

**Q. Caps Lock을 누르면 대문자 고정도 같이 켜져요.**
A. 웹 페이지가 막을 수 없습니다. 한 번 더 눌러 마우스 잠그기를 끄면 원래대로 돌아옵니다.

**Q. Alt+Z를 눌러도 UI가 안 숨겨져요.**
A. Alt+Z는 **NVIDIA 오버레이**의 기본 단축키라서 NVIDIA가 먼저 가로챕니다. **U** 키를 쓰거나 NVIDIA 앱에서 오버레이 단축키를 바꾸세요.

**Q. "No free port between 51730 and 51749" 오류가 나요.**
A. 다른 프로그램이 그 포트들을 쓰고 있습니다. 해당 프로그램을 닫거나 PC를 다시 시작하세요.

**Q. 리테일에서 바쉬르가 안 보여요. 바다만 보여요.**
A. 바쉬르는 깊은 바닷속에 있습니다. **C**나 **X**로 물속까지 내려가세요. [바쉬르](#바쉬르)를 보세요.

**Q. 행성 보기에서 음악이 안 나와요.**
A. 행성 음악은 리테일에서만, 직접 넣은 MP3가 있을 때만 나옵니다([행성 보기 음악](#행성-아제로스-보기) 참고). 처음 실행했을 때 브라우저가 자동 재생을 막으면 화면을 한 번 클릭하세요.

**Q. Retail ⇄ 버튼이 안 보여요.**
A. `app\retail\` 폴더가 있는지 확인하세요. 개발 서버(`npm run dev`)로 실행하면 버튼은 나타나지 않습니다.

## 개발자용 메모

빌드 옵션 `VITE_EDITION` 하나로 클래식과 리테일을 나눕니다(코드에서는 `src/edition.ts`의 `RETAIL`).

| 명령 | 결과 |
|---|---|
| `npm run build` | 타입 검사 후 `dist/`(클래식)와 `dist/retail/`(리테일)를 함께 빌드 |
| `npm run dev` | 클래식 개발 서버 |
| `npm run dev:retail` | 리테일 개발 서버 |
| `npm run portable` | 원작과 같이 포터블 zip 생성 (`app` 안에 리테일도 포함) |

- 포터블 런처는 `app/retail/`을 같은 서버의 `/retail/` 주소로 엽니다.
- 리테일 지역 목록과 볼거리(살게라스의 검, 스톰윈드의 데스윙)의 위치·크기는 `src/explorer/maps.ts`에서 정합니다.
- 행성 보기는 `src/viewer/globe.ts`, 아르거스는 `src/viewer/argus.ts`에 있습니다.
- 스폰·지역 데이터 재생성 같은 원작 도구는 [README.en.md](README.en.md)의 *For developers*를 보세요.
