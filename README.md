# Map Explorer 한국어 포크 (클래식 + 리테일)

내 컴퓨터에 설치된 **월드 오브 워크래프트(WoW)** 게임 파일을 직접 읽어서, 아제로스를 하늘에서 날아다니며 구경할 수 있는 웹 앱입니다.
게임에 로그인하지 않아도 되고, 인터넷도 필요 없습니다. 지도·지형·건물·물·하늘이 모두 **내 PC의 게임 데이터**에서 그려집니다.

이 저장소는 [Coldensjo/ClassicWowMapExplorer](https://github.com/Coldensjo/ClassicWowMapExplorer)(v0.3.1)를 **포크**해서 고친 버전입니다.
원작은 WoW 클래식용이고, 이 포크는 여기에 아래 기능을 더했습니다.

- **리테일(본섭) 에디션**: 칼림도어, 동부 왕국에 더해 **줄다자르**, **혼돈의 소용돌이**, **심원의 영지**까지 리테일 지형으로 볼 수 있습니다. 소용돌이 눈으로 내려가면 심원의 영지로 이어집니다. 실리더스에는 지금 게임처럼 **살게라스의 검**이 꽂혀 있고, 하늘과 우주에는 레기온 7.3의 **아르거스** 행성이 떠 있습니다.
- **행성 아제로스 보기**: 아주 높이 올라가거나 **O** 키를 누르면 아제로스가 우주에서 본 실제 행성처럼 보입니다. 자연색 대륙, 흘러가는 구름, 혼돈의 소용돌이의 회오리 구름까지 그립니다.
- **창 하나에서 클래식 ⇄ 리테일 전환** 버튼 (보던 장소·시점·시간대 유지)
- **낮과 밤이 제대로 바뀌도록** 조명 데이터 읽기 수정 (클래식 에라·리테일 클라이언트용)
- 한낮 지형이 주황빛으로 물들던 문제를 **자연스러운 색감**으로 보정
- **단축키 재배치**: E·D·W·R로 앞·뒤·왼쪽·오른쪽, X로 아래 (아래 표 참고)
- **마우스 조작 변경**: 왼쪽 버튼 드래그로 시점 이동, 좌+우 버튼 동시 누르기로 빠르게 앞으로, **Caps Lock**으로 마우스 잠그기
- **WoW 건틀릿 모양 마우스 포인터** (드래그·좌+우 누르기 중에는 숨김)
- 화면을 클릭하면 **자동으로 전체 화면**, **Alt+Z**(또는 U)로 모든 UI 숨기기
- 창이 **백그라운드에 있으면 소리 자동 음소거**
- **물속도 물 밖처럼 밝고 멀리 보이게** (리테일의 바닷속 지역 **바쉬르**도 둘러볼 수 있음)

> 원작자의 영어 설명서는 [README.en.md](README.en.md)에 그대로 남겨 두었습니다.

## 무엇을 할 수 있나요?

- 동부 왕국과 칼림도어를 **하나로 이어진 세계**로 자유롭게 날아다니기
- 지형 텍스처, 물과 용암, 건물과 소품, 풀·꽃 같은 바닥 장식, 불·연기 파티클
- 게임 자체의 조명 데이터로 그린 **하늘, 안개, 시간대별 빛** (시간 조절 가능)
- 지역 이름과 **지역 음악**, 지역별 환경음 (새소리, 바람, 도시 소음 등)
- 비·눈·모래폭풍 같은 **날씨**
- 게임 속 **세계 지도**와 **미니맵**, 지역·마을 **검색**으로 순간 이동
- **걷기 모드**: 캐릭터를 땅에 내려 게임처럼 뛰고, 점프하고, 수영하기
- (클래식) VMaNGOS 데이터로 만든 **NPC·몬스터**, 비행 경로, 배·비행선 운항, 던전 입구와 만남의 돌
- (리테일) 칼림도어·동부 왕국·**줄다자르**를 리테일 지형으로 비행

## 필요한 것

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10 또는 11 (리눅스·맥은 [소스에서 실행](#소스에서-바로-실행하기-개발-서버)) |
| 게임 | Battle.net으로 설치한 **WoW 클래식**(클래식 에라 포함). 리테일 에디션을 쓰려면 **리테일(본섭)**도 설치되어 있어야 합니다. |
| 브라우저 | Microsoft Edge 또는 Chrome (Windows에는 Edge가 기본으로 있습니다) |
| 직접 빌드할 때만 | [Node.js](https://nodejs.org) 22.12 이상 (LTS 권장), git |

게임은 보통 `C:\Program Files (x86)\World of Warcraft` 에 설치되어 있고, 그 안에 `_classic_era_`, `_classic_`, `_retail_` 같은 폴더가 있습니다.
앱은 이 폴더를 **읽기만** 하고, 어떤 파일도 수정하거나 밖으로 보내지 않습니다.

## 설치 방법 (Windows, 추천)

원작의 **포터블 실행 파일**(`MapExplorer.exe`)에 이 포크에서 빌드한 앱을 넣어 쓰는 방법입니다.
실행 파일은 원작자 릴리스를 그대로 쓰고, 화면에 보이는 앱 부분(`app` 폴더)만 이 포크의 것으로 바꿉니다.

### 1단계. 원작 포터블 버전 받기

1. [원작 v0.3.1 릴리스](https://github.com/Coldensjo/ClassicWowMapExplorer/releases/tag/v0.3.1)에서 **MapExplorer-portable.zip**을 받습니다.
2. 원하는 곳에 압축을 풉니다. 예: `C:\Tools\MapExplorer\`
   압축을 풀면 `MapExplorer\MapExplorer.exe`와 `MapExplorer\app\` 폴더가 생깁니다.

### 2단계. 이 포크 빌드하기

명령 프롬프트(또는 PowerShell)를 열고 차례대로 실행합니다.

```bash
git clone -b ko-edition https://github.com/betraymenow/ClassicWowMapExplorer.git
```

```bash
cd ClassicWowMapExplorer
```

```bash
npm install
```

```bash
npm run build
```

빌드가 끝나면 `dist` 폴더가 생깁니다.

- `dist\` : 클래식 에디션
- `dist\retail\` : 리테일 에디션

### 3단계. app 폴더 바꾸기

1. 1단계에서 푼 `MapExplorer\app` 폴더를 지우거나 다른 이름(예: `app.original`)으로 바꿉니다.
2. 2단계의 `dist` 폴더를 `MapExplorer` 폴더 안에 복사하고, 이름을 **`app`** 으로 바꿉니다.

최종 구조는 다음과 같습니다.

```
MapExplorer\
├─ MapExplorer.exe
├─ app\              ← 이 포크의 dist 폴더
│  ├─ index.html     (클래식)
│  ├─ assets\ ...
│  └─ retail\        (리테일)
└─ README.txt
```

### 4단계. 실행

1. `MapExplorer.exe`를 더블클릭합니다.
2. 처음 실행하면 Windows가 **"Windows의 PC 보호"** 경고를 띄울 수 있습니다. 실행 파일에 서명이 없어서 그렇습니다. **추가 정보 → 실행**을 누르면 됩니다.
3. 앱이 WoW 설치 폴더를 스스로 찾아서 바로 세계가 열립니다.
   못 찾으면 **Choose your World of Warcraft folder** 버튼을 눌러 `World of Warcraft` 폴더(`_classic_era_` 등이 들어 있는 폴더)를 고르세요.

> **포터블 실행 파일이 하는 일**: `app` 폴더를 내 PC 안에서만 접속되는 주소(`http://127.0.0.1:51730`)로 띄우고, Edge를 탭·주소창 없는 **앱 창**으로 엽니다. 창을 닫으면 함께 종료됩니다. 설정은 exe 옆 `data` 폴더에 저장됩니다.

## 소스에서 바로 실행하기 (개발 서버)

포터블 exe 없이, 개발 서버로 실행할 수도 있습니다. 리눅스(Wine 등)나 맥에서도 이 방법을 씁니다.

```bash
npm install
```

클래식 에디션:

```bash
npm run dev
```

리테일 에디션:

```bash
npm run dev:retail
```

그다음 Chrome 또는 Edge에서 **http://localhost:5173** 을 엽니다.
개발 서버도 WoW 설치 위치를 스스로 찾습니다. 다른 곳에 설치되어 있다면 `WOW_DIR` 환경 변수로 알려 주세요.

```bash
WOW_DIR="D:/Games/World of Warcraft" npm run dev
```

> 개발 서버에서는 클래식과 리테일이 서로 다른 서버로 뜨기 때문에 **전환 버튼은 보이지 않습니다.** 전환 버튼은 포터블 방식(위 설치 방법)에서 나타납니다.

## 사용법

1. 3D 화면을 **클릭**하면 **전체 화면**으로 바뀝니다. **Esc**를 누르면 창으로 돌아옵니다.
2. **왼쪽 버튼을 누른 채 드래그**하면 둘러볼 수 있습니다. 드래그하는 동안 포인터는 숨겨지고, 버튼을 떼면 처음 누른 자리에 다시 나타납니다.
3. **E·D·W·R** 키로 앞·뒤·왼쪽·오른쪽으로 날아다닙니다(아래 단축키 표 참고). **Shift**를 누르고 있으면 빨라집니다.
   마우스 **왼쪽+오른쪽 버튼을 함께 누르고 있으면** 빠르게 앞으로 날아갑니다.
4. 마우스만 움직여 둘러보고 싶으면 **Caps Lock**으로 마우스를 잠그세요. 다시 누르면 풀립니다.
5. 화면 왼쪽 위 메뉴에서 여러 설정을 바꿀 수 있습니다.
   - **View**: 시간, 비행 속도, 그림자·안개, NPC·오브젝트 표시, 날씨 등
   - **Sound**: 음악·효과음·환경음 볼륨
   - **Travel**: 비행 경로 타기, 배·비행선 타기, 걷기 모드
   - **Highlight**: 상자·약초·광석·낚시터 등을 멀리서도 보이게 강조
   - **Retail ⇄ / Classic ⇄**: 에디션 전환 ([아래 설명](#클래식--리테일-전환))
6. 오른쪽 위 검색창(**/** 키)에 지역·마을 이름을 입력하면 그곳으로 이동합니다.
7. **F1** 또는 **?** 키를 누르면 단축키 도움말이 나옵니다.
8. **Alt+Z**(또는 **U**)를 누르면 화면의 모든 UI가 숨겨지고 3D 화면만 남습니다. 다시 누르면 돌아옵니다.

## 단축키 전체 목록

이 포크는 원작과 단축키가 다릅니다. **바뀐 키는 굵게** 표시했습니다.

### 비행 (키보드)

| 키 | 동작 | 원작 키 |
|---|---|---|
| **E** / **D** | 앞으로 / 뒤로 | W / S |
| **W** / **R** | 왼쪽 / 오른쪽 | A / D |
| Space | 위로 | Space / E |
| C 또는 **X** | 아래로 | C / Q |
| 방향키 | 앞·뒤·좌·우 | 같음 |
| Shift | 모든 방향 빠르게 (5배) | 같음 |
| **Caps Lock** | 마우스 잠그기 켜기/끄기 | (없음) |
| G | 벽·바닥·땅 통과 켜기/끄기 | 같음 |
| J | 시네마틱 카메라 | 같음 |
| Esc | 전체 화면 끝내기 | 마우스 풀기 |

### 비행 (마우스)

| 동작 | 결과 | 원작 |
|---|---|---|
| **왼쪽 클릭** | 아무 일도 없음. 처음 클릭하면 전체 화면으로 바뀜 | 마우스 잡기 |
| **왼쪽 버튼 드래그** | 시점 이동. 드래그하는 동안 포인터를 숨기고, 버튼을 떼면 처음 누른 자리에 포인터가 다시 나타남 | (없음) |
| 오른쪽 클릭 | 아무 일도 없음 (브라우저 메뉴도 뜨지 않음) | 같음 |
| **왼쪽+오른쪽 동시 누르기** | 누르는 동안 **빠르게 앞으로** (Shift+E와 같은 속도). 이때 다른 방향 키는 보통 속도 | (없음) |
| NPC·오브젝트 클릭 | 정보창 열기 | 같음 |
| 마우스 휠 | 확대 / 축소 | 같음 |
| Caps Lock으로 잠근 상태 | 버튼 없이 마우스만 움직여 시점 이동. 화면 가운데 조준점이 나오고, 클릭하면 조준점 위치의 NPC 정보를 엶 | 클릭으로 잠그기 |

마우스 포인터는 WoW 건틀릿 모양입니다. 손가락 끝이 클릭 지점입니다.

### 장소 이동

| 키 | 동작 | 원작 키 |
|---|---|---|
| / | 지역·마을·맵 검색해서 이동 | 같음 |

| **3 / 4 / 5** | 줄다자르 / 혼돈의 소용돌이 / 심원의 영지 (리테일만) | (없음) |

| **T** | 시작 위치로 돌아가기 | R |

| Esc | 비행 경로·배·비행선에서 내리기 | 같음 |

| ? 또는 F1 | 단축키 도움말 | 같음 |
| (키 없음) | 하이라이트 켜기/끄기 → **Highlight 메뉴의 체크박스** 사용 | H |
| (키 없음) | 비행 속도 올리기/내리기 → **View 메뉴의 Speed 막대** 사용 | Y / Shift+Y |
| (키 없음) | 그림자 켜기/끄기 → **View 메뉴의 Shadows 체크박스** 사용 | X |

**Q**, **A**, **S**, **F** 키는 이 포크의 비행 모드에서 아무 기능도 없습니다.

### 걷기 모드

숫자 1 왼쪽의 **`** 키(또는 Travel 메뉴의 *Walk on the ground*)로 캐릭터를 땅에 내리고, 다시 누르면 비행으로 돌아갑니다.

| 키 | 동작 | 원작 키 |
|---|---|---|
| **E** / **D** | 달리기 / 뒷걸음질 | W / S |
| **W** / **R** | 왼쪽 / 오른쪽으로 돌기 (오른쪽 마우스 버튼을 누르고 있으면 옆걸음) | A / D |
| **X** | 왼쪽 옆걸음 (오른쪽 옆걸음 전용 키는 없음: 오른쪽 버튼 + R) | Q / E |
| Space | 점프, 물속에서는 위로 | 같음 |
| **C** | 물속에서 아래로 | X |
| \ 또는 숫자패드 / | 걷기 / 달리기 전환 | 같음 |
| 왼쪽 마우스 드래그 | 캐릭터 주위로 카메라 돌리기 | 같음 |
| 오른쪽 마우스 누르고 있기 | 캐릭터도 함께 돌기 (두 버튼 동시에 누르면 앞으로 달리기) | 같음 |
| 마우스 휠 | 카메라 거리 (최대 35야드) | 같음 |

## 낮과 밤 바꾸기

처음에는 **내 PC의 현재 시각**에 맞춰 낮과 밤이 정해집니다. 바꾸는 방법은 세 가지입니다.

| 방법 | 설명 |
|---|---|
| **View 메뉴 → Time 막대** | 막대를 끌면 원하는 시각(15분 단위)으로 바로 바뀝니다. 오른쪽 **Now** 버튼은 현재 시각으로 되돌립니다. |
| **Y 키 누르고 있기** | 누르는 동안 시간이 빠르게 흐릅니다. **Shift+Y**는 거꾸로 흐릅니다. |
| **N 키** | 현재 시각으로 되돌립니다. |

- 정오(12:00) 전후는 한낮, 자정(0:00) 전후는 한밤입니다.
- 밤이 너무 어두우면 **L** 키로 횃불 조명을 켜 보세요.

## 물속 표현

원작은 물속에 들어가면 게임처럼 시야가 70~100야드로 좁아지고, 푸른 물빛으로 물들고, 깊이 들어갈수록 어두워졌습니다.
이 포크는 **바다·호수·강 속을 물 밖과 똑같이** 그립니다. (클래식·리테일 모두)

| | 원작 | 이 포크 |
|---|---|---|
| 시야 | 바다 100야드, 호수·강 70야드 | 물 밖과 같음 |
| 색 | 푸른 물빛 안개 | 물 밖과 같은 하늘·안개 |
| 깊이에 따른 어두워짐 | 60야드만 내려가도 최대로 어두워짐 | 없음 |
| 물속 효과음, 수면을 아래에서 본 모습 | 있음 | 그대로 있음 |
| 용암·독액 속 | 짧은 시야, 어두워짐 | 원작과 같음 |

덕분에 해수면 아래 수백~2000야드에 있는 [바쉬르](#바쉬르-둘러보기)도 밝고 멀리까지 보입니다.

## 행성 아제로스 보기

평면 지도를 아주 높이서 보면 아제로스가 **둥근 행성**으로 바뀝니다. (클래식·리테일 모두)

**들어가기**

- **O** 키: 지금 화면 가운데에 보이는 곳을 정면에 두고 행성 보기로 바뀝니다.
- **자동:** 비행하다가 지면에서 **40,000야드** 넘게 올라가면 저절로 바뀝니다.

**조작**

| 조작 | 동작 |
|---|---|
| 왼쪽 버튼 드래그 | 행성 돌리기 (평면 지도처럼 드래그하는 동안 포인터가 숨고, 버튼을 떼면 처음 누른 자리에 다시 나타남). 태양은 우주에 고정된 채 행성만 돌아서, 낮·밤 경계가 대륙 위를 지나감 |
| 마우스 휠 | 확대·축소 |
| 더블클릭 | 그 지점으로 내려가기 |
| 끝까지 확대, 또는 O | 화면 가운데 지점으로 내려가기 |
| 1~5, T | 해당 대륙이나 시작 위치로 바로 이동 |
| Y / Shift+Y | 시간 흐름 (행성의 낮·밤 경계와 해 위치가 움직이고, 구름도 40배 빠르게 흐름. Shift+Y면 거꾸로) |

**행성 모습** (우주에서 본 실제 행성처럼)

행성 보기에서만 자연 행성 모습으로 그리고, 줌인해서 평면 지도로 내려가면 원래 아제로스 맵이 그대로 나옵니다.

- **대륙 색:** 게임의 **미니맵**을 길·건물이 안 보일 만큼 흐리게 한 뒤, 그 색을 가까운 **자연색**으로 바꿉니다. 자연색은 숲, 초원, 관목지, 사막 모래, 붉은 바위, 회색 바위, 화산재, 늪, 눈입니다. 그래서 타나리스는 모래색, 여명의 설원은 하얀 설원처럼 지역 특색이 남습니다. 클래식은 칼림도어·동부 왕국, 리테일은 줄다자르까지 들어갑니다.
- **산맥:** 게임 지형 높이로 음영을 넣고, 높은 곳(상위 20%)과 가파른 비탈은 **숲 사이사이 바위가 드러난 모습**이 됩니다. 눈은 높이와 상관없이 미니맵에서 실제로 눈 덮인 지역에만 그립니다. 그래서 하이잘 산·텔드랏실처럼 높지만 숲인 곳은 하얗게 되지 않습니다.
- **바다:** 짙은 남색 바다, 해안 근처의 청록색 얕은 바다, 극지방의 들쭉날쭉한 해빙을 그립니다. (바다에 비치는 햇빛 반짝임은 흰 점처럼 보여서 뺐습니다.)
- **구름 (GPU로 실시간 생성):** 하늘의 20~25% 정도를 덮고, **반투명**해서 아래 대륙이 살짝 비쳐 보입니다.
  - **일반 구름**은 동쪽으로 천천히 흘러가며 모양이 바뀌고, 땅에 옅은 그림자를 드리웁니다. 대륙 하나를 지나는 데 5분쯤 걸립니다.
  - **혼돈의 소용돌이 구름**(리테일 전용)만 회오리 모양입니다. 제자리에 고정된 채 천천히 돌고(약 3분에 한 바퀴, 일반 구름이 빨라져도 그대로), 가운데 맑은 눈 사이로 붉은 빛이 보입니다. 클래식에서는 소용돌이 없이 일반 구름만 지나갑니다.
  - **Y**로 시간을 빨리 감으면 구름도 40배 빠르게 움직이고, **Shift+Y**면 거꾸로 흐릅니다. 시간 배율 그대로(하루 약 8초)면 구름이 깜빡이기만 해서 따로 정했습니다.
- **아르거스** (리테일): 우주 배경, 아제로스 뒤 오른쪽 아래에 지옥불에 휩싸인 아르거스가 떠 있습니다. 행성을 돌려도 별처럼 배경에 고정되어 있고, 줌아웃하면 전체가 보입니다. 아래 [하늘의 아르거스](#하늘의-아르거스)를 보세요.
- **빈 바다 칸:** 미니맵이 한 가지 색으로만 된 칸(지형 없는 빈 바다)은 육지로 칠하지 않습니다. 잔달라는 이런 칸이 회색이라 바다 한가운데 사각형으로 보였습니다.
- **살게라스의 검** (리테일): 실리더스에 붉은 기운을 두른 검이 서 있습니다. 행성 전체가 보일 때는 실제의 1.6배로 보여 랜드마크처럼 눈에 띄고, 줌인할수록 실제 크기로 줄어 평면 지도와 이어집니다. 구름층보다 높이 솟아 있습니다.
- 가장자리에 붙은 푸른 대기 빛, 보랏빛 성운과 별이 있는 우주 배경, 해와 낮·밤 경계를 그립니다.
- **태양:** 행성 보기에 들어갈 때 현재 시간에 맞는 자리에 놓이고, 그 뒤로는 우주에 고정됩니다. 드래그로 행성을 돌려도 태양은 그대로라 낮·밤이 대륙 위를 지나가고, **Y / Shift+Y**로 시간을 흐르게 하면 태양이 행성의 자전축을 따라 돕니다.
- 행성 보기 동안에는 이름표·지역 이름 같은 지상 표시를 숨깁니다.

**행성 보기 음악** (리테일 전용, 직접 넣는 MP3)

- **리테일 에디션에서만** 재생됩니다. 클래식에서는 행성 보기로 바뀌어도 지역 음악이 그대로입니다.
- 행성 보기로 바뀌면 지역 음악이 서서히 줄고 **행성 전용 음악**이 반복 재생됩니다. 평면 지도로 내려오면 원래 지역 음악으로 돌아갑니다. 지상 환경음(바람 소리 등)도 행성 보기 동안은 꺼집니다.
- 들어갈 때마다 곡의 **처음부터** 재생하고, 끝나면 처음으로 돌아가 반복합니다.
- 페이드인 없이 처음부터 **지역 음악과 같은 최대 음량**으로 재생합니다. 음악 켜기/끄기(**M**)와 사운드 패널의 음악 음량을 그대로 따릅니다.
- 음악 파일은 저장소에 **들어 있지 않습니다**(게임 음악이라 공개하지 않음, `.gitignore`에 포함). 직접 MP3를 **`public/music/planet.mp3`**에 두고 빌드하면 됩니다. 이미 빌드된 앱이라면 `app/music/planet.mp3`와 `app/retail/music/planet.mp3`에 넣어도 되지만, 다음 빌드 때 덮어써집니다. 파일이 없으면 행성 보기는 조용합니다.
- HUD의 음악 칸에 곡 이름(지금은 "Argus", `viewer.ts`의 `PLANET_MUSIC`)이 표시됩니다.

**평면 지도와 위치 맞추기**

- 들어갈 때와 나올 때 모두, **화면 가운데 지점**과 **확대 정도**가 이어지도록 맞춥니다. 예를 들어 소용돌이를 화면 가운데 두고 O를 누르면 행성에서도 소용돌이가 정중앙에 오고, 다시 내려오면 소용돌이가 화면 가운데에 옵니다.
- 공식 지구본 지도가 없어서, 이 앱의 대륙 배치를 **가운데에서 바깥으로 펼치듯** 행성에 씌웁니다. 세계 중심에서 남북 끝까지 약 86°입니다. 그래서 극 근처 대륙이 옆으로 찌그러지지 않고, 행성이 화면을 크게 채웁니다. 나머지는 바다와 구름입니다.
- 행성을 어디로 돌려도 **지도의 북쪽이 화면 위**를 향하도록 기울입니다. 그래서 어느 지점에서 내려가도 평면 지도와 방향이 맞습니다.
- 구름을 매 화면 GPU로 계산해서, 처음 행성으로 들어갈 때 1~2초 멈칫할 수 있습니다.
- 행성을 **처음 열 때** 대륙 그림을 차례로 불러오느라, 잠깐 바다만 보이다가 위쪽부터 채워집니다.

## 클래식 ⇄ 리테일 전환

[포터블 방식](#설치-방법-windows-추천)으로 설치했다면, 화면 왼쪽 위 메뉴(View · Sound · Travel · Highlight) 오른쪽에 버튼이 하나 더 있습니다.

- 클래식 화면: **Retail ⇄** 를 누르면 리테일로 바뀝니다.
- 리테일 화면: **Classic ⇄** 를 누르면 클래식으로 돌아갑니다.

전환해도 그대로 유지되는 것:

| 항목 | 설명 |
|---|---|
| **장소와 시점** | 보던 위치, 높이(지면 기준), 방향, 기울기 그대로 상대 버전이 열립니다. 움직이는 중에 눌러도 누른 순간의 위치를 씁니다. |
| **시간대** | Y·Shift+Y나 View 메뉴의 Time 막대로 바꾼 시각이 그대로 넘어가고, 거기서부터 계속 흐릅니다. 내 PC 시각을 쓰고 있었다면 상대 버전도 내 PC 시각으로 열립니다. |
| **설정** | 두 에디션은 설정을 함께 씁니다(하이라이트, 소리, 표시 거리 등). |

알아 두면 좋은 점:

- 전환하면 페이지를 새로 읽고 게임 데이터를 다시 불러오므로 **몇 초 로딩**이 있습니다.
- 상대 버전에 없는 장소에서 전환하면 시작 위치(엘윈 숲)에서 열립니다. 리테일의 **줄다자르·혼돈의 소용돌이·심원의 영지**, 클래식의 **던전·레이드 맵**이 그렇습니다.
- 높이는 "지면에서 몇 야드 위"로 유지되므로, 대격변으로 지형이 바뀐 곳에서는 절대 높이가 조금 달라질 수 있습니다.
- 시간대는 같은 브라우저 탭 안에서만 넘어갑니다. 넘겨받은 뒤 바로 지우기 때문에, 새로고침(F5)하면 내 PC 시각으로 돌아갑니다.
- 리테일 버튼은 `app\retail\` 폴더가 있을 때만 나타납니다.

## 리테일 에디션 안내와 한계

리테일 에디션은 리테일(본섭) 클라이언트의 지형 데이터를 읽어서 보여 줍니다.

**보이는 지역**

- **동부 왕국**과 **칼림도어**: 대격변 이후의 리테일 지형. **실리더스**는 격전의 아제로스 이후 모습(상처 구덩이와 **살게라스의 검**)입니다. 아래 [실리더스와 살게라스의 검](#실리더스와-살게라스의-검)을 보세요.
- **바쉬르**(대격변 바닷속 지역): 별도 맵이 아니라 **동부 왕국 서쪽 바다 아래**에 들어 있습니다. 아래 [바쉬르 둘러보기](#바쉬르-둘러보기)를 보세요.
- **줄다자르**(격전의 아제로스 대륙): 두 대륙 남쪽 바다 가운데에 놓입니다. **3** 키로 바로 이동할 수 있습니다. 잔달라 지도의 빈 바다에 깔린 **회색 평판 칸**(지형 없이 해수면 위에 평평하게 놓인 채움용 칸)은 빼서, 바다 위에 판자가 떠 보이지 않게 했습니다.
- **혼돈의 소용돌이**(대격변): 게임처럼 칼림도어와 동부 왕국 **사이 바다 한가운데**에 있습니다. **4** 키로 바로 이동할 수 있습니다.
- **심원의 영지**(대격변): 소용돌이 **아래 땅속**에 있습니다. 소용돌이 눈으로 내려가면 이어지고, **5** 키로 바로 갈 수도 있습니다. 아래 [혼돈의 소용돌이와 심원의 영지](#혼돈의-소용돌이와-심원의-영지)를 보세요.
- 던전, 레이드, 다른 대륙(노스렌드, 판다리아, 쿨 티라스 등)은 **일부러 넣지 않았습니다.**

### 혼돈의 소용돌이와 심원의 영지

**소용돌이 → 심원의 영지 (내려가기)**

1. **4** 키로 혼돈의 소용돌이로 갑니다. 미니맵의 소용돌이 한가운데가 **소용돌이 눈**입니다.
2. 눈 위에서 **C** 또는 **X**(아래로)를 누르고 있습니다. **Shift**를 같이 누르면 빨리 내려갑니다.
3. 눈(중심 반경 200야드) 안에서 **해수면 아래 300야드**를 지나면 화면이 잠깐 어두워졌다가, **심원의 영지 대지의 사원 위 1,150야드 상공**에서 계속 내려가는 장면으로 이어집니다.

**심원의 영지 → 소용돌이 (올라가기)**

- 대지의 사원 주변(반경 900야드)에서 **1,350야드** 위로 올라가면 다시 소용돌이 눈 안으로 올라옵니다.

**알아 두면 좋은 점**

- 소용돌이 눈의 중심과 **대지의 사원 중심**이 맞물려 있습니다. 눈에서 떨어진 거리와 방향이 그대로 사원 기준으로 옮겨지고, 반대 방향도 같습니다.
- 소용돌이 눈 안에서는 바닥에 막히지 않습니다. 눈을 벗어난 곳은 해저 바닥(-270야드 안팎)에 막혀 넘어가지 않습니다.
- 이 앱의 지형은 평면 격자라 두 맵을 위아래로 겹칠 수 없습니다. 그래서 심원의 영지는 평면 지도와 행성 보기에서 보이지 않는 먼 곳에 두고, 소용돌이와는 위 장면 전환으로 잇습니다.
- 대지의 사원 **건물 안**에서는 천장에 막혀 올라갈 수 없습니다. 밖에서 올라가거나 **G**(벽 통과)를 켜세요.
- 심원의 영지는 게임 자체 조명 데이터가 아주 어둡고 푸릅니다(땅속이라서). 이 앱에서는 **심원의 영지에서만** 직사광을 2.3배, 주변광을 3.6배, 하늘·안개를 2배 밝게 합니다. 푸른 색조도 40% 정도 무채색 쪽으로 옮겨 지형이 잘 보이게 했습니다.
- 소용돌이 물과 구름은 지형이 아니라 거대한 모델입니다. 그래서 소용돌이 맵은 **8,000야드** 안에 들어오면 전체를 상세하게 불러와 멀리서도 실제 모습이 보이게 했습니다. 맵 가장자리 사각형 부분은 모델이 덮지 않아 주변 바다보다 어둡게 보일 수 있습니다.

### 하늘의 아르거스

레기온 7.3 때처럼, 지옥불에 휩싸인 **아르거스**가 아제로스 하늘에 떠 있습니다. 게임 파일에는 아제로스 하늘에서 본 아르거스 모델이 남아 있지 않아서, 셰이더로 직접 그렸습니다(`argus.ts`).

- **모습:** 어두운 보랏빛 바위 위로 노란·초록 지옥불 균열과 반점이 맥동합니다. 왼쪽 아래에는 주황·노랑으로 소용돌이치는 녹은 상처와 떠다니는 바위 파편이 있고, 가장자리에는 초록·청록 지옥불 불꽃이 일렁입니다. 해 방향에 따라 밝은 면이 생기고, 밤에도 지옥불 빛으로 보입니다.
- **평면 지도:** 동남동쪽 하늘, 지평선에서 약 33° 위에 시야각 약 20° 크기로 떠 있습니다(`ARGUS_SKY_DIRECTION`, `ARGUS_SKY_SIZE`). 하늘 바로 다음에 그려서 산과 건물이 앞을 가리고, 안개에 묻히지 않습니다. 지하(심원의 영지)나 물속처럼 하늘이 안 보이는 곳에서는 나타나지 않습니다.
- **행성 보기:** 우주 배경, 아제로스 뒤 오른쪽 아래에 고정되어 있습니다(`globe.ts`의 `ARGUS_POSITION`, `ARGUS_RADIUS`). 하늘에서 보이는 방향 그대로 두면 카메라 뒤쪽이 되어 보이지 않기 때문입니다.
- 리테일 에디션에만 있습니다(켜기/끄기 없음).

### 실리더스와 살게라스의 검

- 지금 게임의 실리더스는 칼림도어 기본 지도가 아니라 **지형 교체 맵 "Silithus: The Wound"(맵 1817)**에 들어 있습니다. 기본 지도에는 검이 꽂히기 전의 옛 실리더스가 남아 있습니다.
- 그래서 리테일에서 칼림도어를 읽을 때 실리더스 **25개 타일(5×5)**을 이 지형 교체 맵 것으로 바꿉니다. 상처 구덩이, 빛나는 아제라이트 균열, 검이 모두 게임과 같은 위치·기울기로 나옵니다.
- **살게라스의 검**은 높이 약 3,000야드가 넘는 거대한 건물형 모델(WMO)입니다. 검이 있는 타일만 **45,000야드** 밖에서도 불러오고, 반경 1,500야드가 넘는 초대형 모델은 거리 제한 없이 보입니다. 그래서 칼림도어 어디서든, 아주 높이 올라가도 검이 보입니다.
- **붉은 기운과 연기 자락**: 게임 서버가 띄우는 효과 모델이라 지도 파일에 없어서 검과 같은 자리에 직접 놓았습니다. 검을 감싼 붉은 균열과 줄기, 그 사이로 번갈아 나타나는 **어두운 연기 자락**이 이 모델입니다.
  - 이 효과는 레이어마다 **텍스처 두 장**을 곱해서 그립니다. 첫 장은 흰 모양 마스크이고, 둘째 장이 붉은 에너지 무늬와 연기 결입니다.
  - 연기 줄기 레이어는 **색 애니메이션**(흰색 → 검은색 → 흰색)으로 붉은 줄기와 어두운 연기를 오갑니다.
  - 게임은 이 레이어를 **배경을 어둡게도 할 수 있는 방식**(premultiplied alpha)으로 섞습니다. 그래서 어두운 연기가 보입니다.
  - 원래 이 앱은 첫 텍스처만 쓰고 빛을 더하는 방식으로만 그려서, 흰 줄무늬만 보이고 연기는 보이지 않았습니다. 지금은 위 세 가지를 **검 효과 모델에만** 게임처럼 적용합니다. 다른 모델은 두 번째 텍스처를 반사광처럼 다른 용도로 쓰기도 해서 그대로 둡니다.
- **구덩이 연기**: 지도 파일에 있는 연기 모델도 검과 함께 멀리서도 보이게 했습니다. 큰 모델의 연기 입자는 크기에 비례해 멀리서도 나옵니다(이 연기는 약 4,400야드). 다만 파일 값상 입자 하나가 지름 8야드 정도로 작고 거의 투명해서, 거대한 검 옆에서는 거의 보이지 않습니다.
- 행성 보기에도 같은 검과 붉은 기운이 서 있습니다. 연기 입자는 행성 크기에서 보이지 않아 넣지 않았습니다.
- 검과 효과가 크기 때문에 처음 실리더스 근처로 가면 나타나기까지 최대 1분쯤 걸릴 수 있습니다.
- 클래식 에디션의 실리더스는 그대로입니다.

### 바쉬르 둘러보기

바쉬르(켈프타르 숲, 일렁이는 해원, 심연의 나락)는 해수면 아래 **250~2100야드** 깊이에 있습니다.

1. `/` 검색에서 **Kelp'thar Forest**, **Shimmering Expanse**, **Abyssal Depths** 등을 찾아 이동합니다.
2. 바다 위에 도착하면 **C** 또는 **X**(아래로)를 누르고 있습니다. **Shift**를 같이 누르면 빨리 내려갑니다.
3. 해저에 가까워지면 산호, 해초, 암반 지형이 보입니다.

이 포크는 물속도 물 밖처럼 그리므로(아래 [물속 표현](#물속-표현) 참고) 깊은 바쉬르도 밝고 멀리까지 보입니다.

**한계**

- **NPC와 몬스터는 표시하지 않습니다.** 이 앱의 NPC 배치 데이터는 클래식(1.12) 기준이라 리테일 지형과 맞지 않기 때문입니다. View 메뉴에서도 NPC 항목이 빠져 있습니다.
- 상자·약초·광석 같은 **오브젝트**, 지역 이름, 비행 경로, 배·비행선 데이터도 클래식 기준입니다. 그래서 리테일 지형과 위치가 어긋날 수 있습니다. 오브젝트는 View 메뉴의 *Objects* 체크박스로 끌 수 있습니다.
- 줄다자르에는 클래식 지역 데이터가 없어서, 정보창에 지역 이름 대신 `Zandalar - tile 29_37` 처럼 타일 번호가 나옵니다.
- 블리자드가 암호화해 둔 일부 리테일 파일은 읽을 수 없습니다.
- 줄다자르 맵 파일에는 본섬과 떨어진 작은 지형 조각이 몇 개 들어 있어서, 섬 옆 바다에 함께 보입니다.

## 자주 묻는 질문 / 문제 해결

**Q. "Windows의 PC 보호" 창이 떠요.**
A. 실행 파일에 디지털 서명이 없어서 나오는 경고입니다. **추가 정보 → 실행**을 누르세요.

**Q. 게임 폴더를 못 찾는다고 나와요.**
A. **Choose your World of Warcraft folder**를 눌러, `_classic_era_`·`_retail_` 등이 들어 있는 **World of Warcraft 폴더 자체**를 고르세요. 그 안의 `_classic_era_` 폴더를 고르면 안 됩니다. 창에 "업로드"라고 나와도 파일은 내 PC 밖으로 나가지 않습니다.

**Q. 클래식 버전인데 오리지널 클래식 지도가 아니고, 소리도 안 나요.**
A. 판다리아 클래식 같은 **클래식 진행 서버**(`wow_classic`)를 함께 설치하면 생길 수 있었습니다. 원작은 이름이 `wow_classic`으로 시작하는 게임 중 먼저 나오는 것을 골라서, 대격변 이후 지형인 판다리아 클래식을 열었습니다. 일부만 받아진 설치본이면 음악 등 데이터를 읽지 못해 HUD에 "Music: unavailable"이 뜹니다. 이 포크는 **클래식 에라(`wow_classic_era`)를 가장 먼저** 고르도록 고쳤습니다.

**Q. 시간이 지나도 낮과 밤이 안 바뀌어요.**
A. 원작은 WoW Forever(클래식 베타) 클라이언트의 조명 데이터 구조에 맞춰져 있어서, 클래식 에라·리테일에서는 조명을 읽지 못했습니다. 이 포크에서 고쳤습니다. 여전히 그렇다면 창에서 **F5**로 새로고침해 보세요.

**Q. 한낮 화면이 주황빛이에요.**
A. 게임 데이터의 직사광 색이 지역에 따라 강한 주황(예: 엘윈 숲 정오 `#FF8800`)이라서 생기는 현상입니다. 이 포크는 직사광의 밝기는 그대로 두고 색조의 75%를 해의 색으로 바꿔 자연스럽게 보정합니다. 세기는 `src/viewer/lighting.ts`의 `DIRECT_NATURAL` 값으로 조절할 수 있습니다(0 = 게임 원래 색, 1 = 해의 색만).

**Q. 다른 창을 보고 있으면 소리가 안 나요.**
A. 이 포크는 Map Explorer 창이 **포커스를 잃거나 최소화되면 자동으로 음소거**합니다. 창으로 돌아오면 바로 다시 소리가 납니다. 앱의 **M** 키로 직접 끈 소리는 돌아와도 계속 꺼져 있습니다.

**Q. 전체 화면은 어떻게 하나요?**
A. 3D 화면을 클릭하면 자동으로 전체 화면이 됩니다. **Esc**를 누르면 창으로 돌아오고, 다시 클릭하면 또 전체 화면이 됩니다. **F11**로도 켜고 끌 수 있습니다.
클래식⇄리테일 전환이나 새로고침을 하면 페이지를 새로 열기 때문에 전체 화면이 풀립니다.

**Q. 화면 위에 "Esc를 누르면 …" 같은 안내 문구가 떠요.**
A. Edge 브라우저가 전체 화면에 들어가거나 마우스를 잠글 때 띄우는 보안 안내입니다. 웹 페이지가 끌 수 없습니다. 이 포크는 문구가 덜 뜨도록, 그냥 클릭할 때는 마우스를 잠그지 않고 드래그할 때와 Caps Lock을 눌렀을 때만 잠급니다.

**Q. Caps Lock을 누르면 대문자 고정도 같이 켜져요.**
A. Windows의 대문자 고정은 웹 페이지가 막을 수 없습니다. 마우스 잠그기를 켰다가 끄면(두 번 누르면) 원래 상태로 돌아옵니다. 마우스가 잠긴 상태에서 Esc를 누르면 브라우저가 잠금을 풉니다.

**Q. 드래그 후 포인터가 처음 위치에서 조금 어긋나요.**
A. 그냥 클릭할 때 마우스가 잠기지 않도록, 4픽셀 정도 움직인 뒤에 잠그기 때문입니다. 웹 페이지는 포인터 위치를 직접 옮길 수 없어서, 드래그 중에 마우스를 잠가 포인터를 제자리에 두는 방식을 씁니다.

**Q. Alt+Z를 눌러도 UI가 안 숨겨져요.**
A. Alt+Z는 **NVIDIA 오버레이**(GeForce Experience / NVIDIA 앱)의 기본 단축키라서, 오버레이가 켜져 있으면 NVIDIA가 먼저 가로챕니다. **U** 키를 쓰거나 NVIDIA 앱 설정에서 오버레이 단축키를 바꾸세요.

**Q. "No free port between 51730 and 51749" 오류가 나요.**
A. 다른 프로그램이 그 포트들을 쓰고 있습니다. 해당 프로그램을 닫거나 PC를 다시 시작하세요.

**Q. 리테일에서 바쉬르가 안 보여요. 바다만 보여요.**
A. 바쉬르는 해수면 아래 250~2100야드에 있어서 바다 위에서는 수면만 보입니다. **C**나 **X**로 물속까지 내려가세요(Shift를 함께 누르면 빠름). 자세한 방법은 [바쉬르 둘러보기](#바쉬르-둘러보기)를 보세요.

**Q. Retail ⇄ 버튼이 안 보여요.**
A. `app\retail\` 폴더가 있는지 확인하세요. 개발 서버(`npm run dev`)로 실행하면 버튼은 나타나지 않습니다.

## 이 포크에서 바뀐 점 (개발자용)

### 빌드 구조

빌드 옵션 `VITE_EDITION` 하나로 클래식과 리테일을 나눕니다. 코드에서는 `src/edition.ts`의 `RETAIL` 상수로 구분합니다.

| 명령 | 결과 |
|---|---|
| `npm run build` | 타입 검사 후 `dist/`(클래식)와 `dist/retail/`(리테일)를 함께 빌드 |
| `npm run dev` | 클래식 개발 서버 |
| `npm run dev:retail` | 리테일 개발 서버 (`.env.retail`의 `VITE_EDITION=retail` 사용) |
| `npm run portable` | 원작과 같이 포터블 zip 생성 (mingw-w64, ImageMagick, 7-Zip 필요). `app` 안에 리테일도 포함됩니다. |

### 포터블 런처와 /retail/

원작의 포터블 런처(`MapExplorer.exe`)는 `app` 폴더 아래 하위 폴더도 그대로 서빙합니다. 그래서 `app/retail/`에 리테일 빌드를 두면 같은 서버(`127.0.0.1:51730`)의 `/retail/` 주소로 열립니다.
리테일 빌드도 게임 파일은 루트의 `/__wow/`에서 읽어야 하므로, `main.ts`에서 게임 파일 주소를 상대 경로(`__wow/`)에서 루트 기준(`/__wow/`)으로 바꿨습니다.

### 원작의 도구들

스폰 데이터 재생성(`npm run spawns`), 지역 데이터 재생성(`npm run regions`), 게임 데이터 점검(`npm run probe`) 등은 원작과 같습니다. 자세한 내용은 [README.en.md](README.en.md)의 *For developers*를 보세요.
